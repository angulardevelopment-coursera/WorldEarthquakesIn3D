World Earthquakes in 3D

Explore recent earthquake activity around the world using this interactive three-dimensional globe. Earthquake markers show the location, magnitude and depth of recorded events. Rotate the globe to examine different regions, zoom in for a closer look, and select an individual marker to view its details.

How to use the earthquake visualisation

  • Select Load Live Data to retrieve the latest available earthquake feeds.
  • Drag with the left mouse button to rotate the globe.
  • Drag with the right mouse button to move the view.
  • Use the mouse wheel or trackpad to zoom in and out.
  • Set the date range and window size, then use Play Animation to move through the selected period.
  • Select an earthquake marker to see its source, magnitude, depth, location and date/time.

Earthquake data sources

The visualisation combines publicly available earthquake information from Geoscience Australia, the United States Geological Survey (USGS), and the European-Mediterranean Seismological Centre (EMSC). Events from the feeds are compared and likely duplicates are removed before the markers are displayed.

Geoscience Australia

Australian earthquake information is retrieved from the Geoscience Australia earthquake service. Its feed used here covers approximately the most recent seven days.

Understanding the markers

Marker size represents earthquake magnitude. Marker colour represents depth: shallow events are red, intermediate-depth events are orange, and deeper events are purple. Marker position is based on the recorded latitude, longitude and depth.

About this project

World Earthquakes in 3D is an interactive data-visualisation project built with JavaScript and Three.js. It brings together public earthquake feeds and presents the information in a form that makes global patterns easier to explore.
